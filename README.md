
Репозиторий содержит готовые конфигурационные файлы (JSON) для **Xray-core**, а также бэкапы для **Karing** и **Incy**, ссылки формата `vless://` / `hysteria2://` для быстрых подключений и интеграцию с белыми списками.

Наши конфигурации основаны на серверах **Capybara (Capynode / Capycore)** и от **[igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia)** для белых списков и обхода блокировок. Они оптимизированы для обеспечения высокой скорости, минимальной задержки (ping) в играх и стабильной работы.

## ✨ Особенности

- **🛡 Маскировка Reality & TLS**: Использование протокола VLESS с техникой REALITY маскирует трафик под обычные посещения легитимных сайтов.
- **🎮 Hysteria 2 для игр и низкого пинга**: Протокол на базе QUIC/UDP с регулятором BBR идеально подходит для онлайн-игр и нестабильных мобильных сетей.
- **🔀 Умное разделение трафика и Белые списки**:
  - **Напрямую (Direct)**: Российские сервисы (Госуслуги, Банки, Ozon, Wildberries, VK, Yandex), BitTorrent-торренты, сервисы Apple/Google Push.
  - **Через прокси (Proxy)**: Заблокированные ресурсы, социальные сети, зарубежные медиа-сервисы, YouTube, Xbox/Microsoft.
- **📦 Файлы восстановлений (Backup)**: Включены готовые файлы бэкапов для быстрого импорта всех настроек в **Karing** и **Incy**.
- **🔄 Автообновление**: Поддержка подключения через Raw-ссылки GitHub для автообновления конфигураций без ручной перекачки.

## ⚡ Поддерживаемые протоколы

1. **VLESS + XTLS-Vision + REALITY**
   - Порт: `443`
   - Маскировка (SNI): `spb.capynode.com`, `de.capynode.com`, `yandex.ru`, `vk.com` и др.
   - Fingerprint: `firefox`, `qq`, `chrome`
2. **Hysteria 2 (UDP/QUIC)**
   - Порт: `443`
   - ALPN: `h3`
   - Контроль перегрузок: `BBR`
3. **VLESS + XHTTP / WebSocket**
   - Резервное подключение через WebSockets и XHTTP (Packet-up mode).

### Способ 1. Автообновление по Raw-ссылке (Рекомендуется)

Чтобы конфиги обновлялись автоматически и вам не нужно было каждый раз скачивать файлы заново:

1. Откройте нужный `.json` файл в этом репозитории на GitHub.
2. Нажмите кнопку **«Raw»** в правом верхнем углу просмотра файла и скопируйте ссылку из адресной строки браузера.
3. Откройте ваш клиент (Karing, v2rayN, NekoBox, v2raytun и др.), перейдите в раздел подписок/конфигураций и выберите **«Добавить по ссылке / URL»**.
4. Вставьте скопированную Raw-ссылку. Теперь конфиг будет подтягивать свежие изменения при каждом обновлении репозитория!

---

### Способ 2. Восстановление бэкапов в Karing и Incy

В репозитории добавлены готовые файлы бэкапов для быстрой и полной настройки приложений **Karing** и **Incy**:

1. Скачайте нужный файл бэкапа для **Karing** или **Incy** из репозитория.
2. Откройте приложение (**Karing** или **Incy**).
3. Перейдите в **Настройки -> Резервное копирование и восстановление (Backup / Restore)**.
4. Выберите пункт **Восстановить (Restore)** и укажите скачанный файл бэкапа. Все профили, узлы и правила маршрутизации подгрузятся автоматически.

---

### Способ 3. Импорт по URIs (VLESS / Hysteria2)

1. Скопируйте одну или несколько URIs (начинаются с `vless://` или `hysteria2://`).
2. Откройте ваш клиент (например, NekoBox или v2rayN).
3. Нажмите кнопку **«Импорт из буфера обмена»** (Import from clipboard / `Ctrl+V`).
4. Выберите нужный сервер и нажмите **«Подключиться»**.

## 🧠 Умная маршрутизация и Белые списки

Маршрутизация выстроена с использованием правил из баз `geosite` / `geoip` и от **[igareck](https://github.com/igareck/vpn-configs-for-russia)**:

- **Direct (Прямое подключение / Белый список)**:
  - Российские веб-ресурсы, государственные сайты и банки (`gosuslugi.ru`, `nalog.gov.ru`, `tinkoff.ru`, `ozon.ru`, `wildberries.ru`, `yandex.ru`, `vk.com`, `2gis.ru`).
  - Торренты (`protocol: bittorrent`).
  - Push-уведомления (`mtalk.google.com`, `push.apple.com`).
  - Категории `geosite:private`, `geosite:category-ru`.
- **Proxy (Через прокси)**:
  - Заблокированные домены (`habr.com`, `4pda.to`, `xboxlive.com`, `microsoft.com`, `azure.com` и др.).
  - Весь остальной заблокированный или международный трафик.
